В задаче требовалось написать функцию, которая принимает возраст человека и выводит его возрастную категорию:
Minor (Несовершеннолетний) — если возраст меньше 18 лет.
Adult (Взрослый) — если возраст от 18 до 64 лет включительно.
Senior (Пожилой) — если возраст 65 лет и старше.

fun category (a: Int) {
    if (a < 18){
        println("Minor")
    } else if (a in 18..64){
        println("Adult")
    } else {
        println("Senior")
    }
}

fun main() {
    val age = readLine()!!.toInt()
    category(age)
}

Выделение последней цифры: 
Функция должна отсекать всё число и оставлять только его последнюю цифру справа (например, из 12345 получить 5).
Игнорирование знака «минус»: Функция должна возвращать строго модуль (абсолютное значение) этой цифры. 
Если число отрицательное (например, -512), результатом должна быть положительная цифра 2, а не -2.

import kotlin.math.abs

fun getLastDigit (a: Int): Int {
    return abs(a) % 10
}

fun main() {
    val a = readln().toInt()
    println(getLastDigit(a))
}

Write a function printIfPrime(number: Int) that:
Prints "<number> is a prime number." if the number is prime.
Prints "<number> is not a prime number." otherwise.
1 is not a prime number.
Use a loop to check divisors up to sqrt(number).

Example:
5 → "5 is a prime number."
12 → "12 is not a prime number."

import kotlin.math.sqrt                       		 // импортируем функцию для вычисления квадратного корня

fun printIfPrime(number: Int) {                           // функция проверяет, является ли число простым, и печатает результат
    if (number <= 1) {                                    // если число меньше или равно 1
        println("$number is not a prime number.")         // печатаем, что число не простое
        return                                            // выходим из функции
    }

    var flag = true                                              // переменная-флаг: true — число простое, false — составное
    val limit = sqrt(number.toDouble()).toInt()       		 // вычисляем границу проверки (корень из числа, если делителя до корня нет - число простое)
    for (i in 2..limit) {                             		 // перебираем все числа от 2 до корня
        if (number % i == 0) {                                   // если число делится на i без остатка
            flag = false                                         // число составное
            break                                                // выходим из цикла (дальше проверять не нужно)
        }
    }
    if (flag) {                                                  // если флаг остался true
        println("$number is a prime number.")                    // число простое
    } else                                                       // если флаг false
        println("$number is not a prime number.")                // число составное
}

fun main(args: Array<String>) {                                  // точка входа в программу
    val number = readln().toInt()                                // читаем число с клавиатуры
    printIfPrime(number)                                         // вызываем функцию проверки
}
