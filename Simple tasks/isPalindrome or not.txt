Write a function that takes a CharSequence (string) and returns true if it reads the same forward and backward (palindrome), otherwise false.

Example:
"racecar" → true
"sky" → false


fun isPalindrome(str: CharSequence): Boolean {
    return if ("$str" == "${str.reversed()}") true else false
}
