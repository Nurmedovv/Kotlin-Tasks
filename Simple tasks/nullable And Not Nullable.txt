Write a function nullOrNotNull that takes a nullable Int? parameter number.
Return -1 if number is null, otherwise return the number itself.

fun nullOrNotNull (number: Int?): Int {
    if (number == null) {
        return -1
    }
    return number
}

Given a nullable String? value line.
Print its length if it's not null, otherwise print -1.

Example:
Input: "Kotlin" → Output: 6
Input: null → Output: -1

fun main() {
    val line: String? = readLine()
    println(line?.length ?: -1)
}

------------------------------------------------------------------------------------

fun main() {
    val line: String? = readLine()
    println(if (line != null) line.length else -1)
}
