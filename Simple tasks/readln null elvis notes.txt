null - отсутствие значения. а 0 - это значение 0.  Int не может быть null. Int? может быть либо Int либо null

-----------------------------------------------------------------------------------------------------------------


?: — это оператор "элвис" (Elvis operator).

Что делает:
Возвращает левое значение, если оно не null.
Если левое значение null — возвращает правое.

val a: Int? = null
val b = a ?: 5  // b = 5, потому что a = null

val c: Int? = 10
val d = c ?: 5  // d = 10, потому что c не null
