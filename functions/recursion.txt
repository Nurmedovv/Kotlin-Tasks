Программа должна вычислить сумму всех целых чисел от 1 до заданного числа n включительно.
Пример:
Вход: 7
Математика: (7 + 6 + 5 + 4 + 3 + 2 + 1 = 28)
Выход: 28

-------------------------------------
fun sumRecursive(n: Int): Int {
    if (n == 0) return 0
    if (n == 1) return 1
    return n + sumRecursive(n - 1)
}

fun main() {
    val n = readln().toInt()
    print(sumRecursive(n))
}
------------------------------------- 

Представь, что мы вызвали функцию для 7. 
Строка кода выглядит так:
return n + sumRecursive(n - 1)

Подставляем семерку:
return 7 + sumRecursive(6)
(Компьютер запомнил 7 и пошел вычислять sumRecursive(6))

Но ведь sumRecursive — это та же самая функция! 
Когда компьютер заходит в неё с шестеркой, он снова натыкается на ту же самую строчку кода n + sumRecursive(n - 1).

Для шестерки она превращается в:return 6 + sumRecursive(5)

А внутри sumRecursive(5) эта строчка превращается в:
return 5 + sumRecursive(4)

sumRecursive(7) 
= 7 + sumRecursive(6)
= 7 + (6 + sumRecursive(5))
= 7 + (6 + (5 + sumRecursive(4)))
= 7 + (6 + (5 + (4 + (3 + (2 + (1))))))

Программа должна вычислить сумму всех цифр заданного числа n.
Пример:Вход: 5421
Математика: (5 + 4 + 2 + 1 = 12)
Выход: 12

fun digitSum(n: Int): Int {
    if (n == 0) return 0
    return (n % 10) + digitSum(n / 10)
}



Пошаговый спуск (как разворачивается стек)

* Этаж 1: Заходим с n = 5421. Условия if не срабатывают.
Код превращается в: return 1 + digitSum(542).
Компьютер ставит сложение на паузу, запоминает цифру 1 и прыгает на этаж ниже.

* Этаж 2: Заходим с n = 542.
Код превращается в: return 2 + digitSum(54).
Запомнили цифру 2, прыгаем ниже.

* Этаж 3: Заходим с n = 54.
Код превращается в: return 4 + digitSum(5).
Запомнили цифру 4, прыгаем ниже.

* Этаж 4: Заходим с n = 5.
Код превращается в: return 5 + digitSum(0).
(Потому что 5 делить нацело на 10 будет 0). Запомнили цифру 5.

* Этаж 5 (Базовый случай): Заходим с n = 0.
Срабатывает твоё первое условие: if (n == 0) return 0.
Рекурсия остановилась и вернула конкретное число 0.

Обратный ход (собираем цифры из «памяти»)
Теперь компьютер снимает с паузы все сложения снизу вверх:

   1. Этаж 4 считает: 5 + 0 = 5 (передает наверх)
   2. Этаж 3 считает: 4 + 5 = 9 (передает наверх)
   3. Этаж 2 считает: 2 + 9 = 11 (передает наверх)
   4. Этаж 1 считает: 1 + 11 = 12

Финальный ответ: 12.

Программа должна проверить, является ли заданное число простым, используя рекурсию.
Функция должна вернуть true, если число простое, и false, если нет.
Пример:
Вход: 3
Проверка: Число 3 делится без остатка только на 1 и на самого себя.
Выход: true

fun isPrime(n: Int, i: Int = 2): Boolean {    // Объявление функции, n — число, i — делитель (старт с 2)
    if (n <= 1) return false                  // Числа 1 и меньше не являются простыми, возвращаем false
    if (n == i) return true                   // Если делитель дополз до самого числа n — число простое
    if (n % i == 0) return false              // Если n депится на i без остатка — число не простое
    return isPrime(n, (i + 1))                // Переходим к следующему шагу, увеличив делитель на 1
}                                             // Конец функции isPrime

fun main() {                                  // Главная функция, с которой начинается запуск программы
    val n = readln().toInt()                  // Считываем строку из консоли и переводим её в число
    print(isPrime(n))                         // Вызываем проверку для числа n и выводим true или false
}                                             // Конец программы

Условие задачи:

Реализовать рекурсивную функцию f(n), которая вычисляется по формуле:
- f(n) = f(n-1)/2 + 2*f(n-2) для `n > 0`
- Базовые случаи: f(0) = 4, f(-1) = 1
- Функция должна возвращать целое число (использовать целочисленное деление)
- Для n = 5 результат должен быть 39

Требование: Использовать рекурсию с мемоизацией (кешированием) для избежания повторных вычислений.

Пример:
- Ввод: 5
- Вывод: 39

lateinit var cache: MutableList<Int?>                             // кеш для мемоизации (будет инициализирован позже)

fun f(n: Int): Int {                                              // рекурсивная функция для вычисления f(n)
    if (n == 0) return 4                                          // базовый случай: f(0) = 4
    if (n == -1) return 1                                         // базовый случай: f(-1) = 1	
    
    val cachedValue = cache[n]                                    // берём значение из кеша по индексу n
    
    return if (cachedValue != null) cachedValue                   // если значение есть в кеше — возвращаем его
    else {                                                        // если значения в кеше нет — вычисляем
        val result = f(n - 1) / 2 + 2 * f(n - 2)                  // вычисляем по формуле: f(n-1)/2 + 2*f(n-2)
        cache[n] = result                                         // сохраняем результат в кеш
        return result                                             // возвращаем результат
    }
}

fun main() {                                                      // точка входа в программу
    val n = readln().toInt()                                      // считываем число n с клавиатуры
    cache = MutableList<Int?>(n + 1) { null }                     // создаём список размером n+1, заполняем null
    print(f(n))                                                   // вычисляем f(n) и выводим результат
}
