Вам требовалось создать функцию, которая:
Принимает 3 строки и 1 разделитель.
Соединяет эти три строки по порядку, вставляя разделитель между ними.
Использует пробел, если разделитель не был передан при вызове.
Возвращает одну готовую склеенную строку.

fun concatenate(s1: String, s2: String, s3: String, sep: String =  " "): String {
    return ("$s1$sep$s2$sep$s3")
}

Создать одну универсальную функцию с именем polynomial.
Объединить три разные функции в одну общую формулу: (a * x * x + b * x + c).
Сохранить порядок параметров, как в самой длинной функции из условия: сначала x и c, затем b, и в самом конце a.
Использовать аргументы по умолчанию (равные 0) для коэффициентов b и a, чтобы функцию можно было успешно вызывать с двумя, тремя или четырьмя числами.

fun polynomial(x: Int, c: Int, b: Int = 0, a: Int = 0): Int {
    return a * x * x + b * x + c 
}

Установить ограничение по умолчанию равным 60 км/ч, если другой лимит не задан.
Сравнить скорость автомобиля с лимитом и высчитать разницу, если скорость выше разрешенной.
Вывести правильный текст в консоль: "Exceeds the limit by N kilometers per hour", если скорость превышена, или "Within the limit", если всё в порядке.

fun checkSpeed(speed: Int, limit: Int = 60) {
    val n: Int

    if (speed > limit){
        n = speed - limit
        println("Exceeds the limit by $n kilometers per hour")
    } else {
        println("Within the limit")
    }
}
