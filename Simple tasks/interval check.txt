Требуется проверить, попадает ли целое число в один из трёх интервалов, и вывести True или False.
Математические условия для интервалов:

   1. От -15 (исключая) до 12 (включая): x > -15 && x <= 12
   2. От 14 (исключая) до 17 (исключая): x > 14 && x < 17
   3. От 19 (включая) и больше: x >= 19


fun main() {
    val a = readln().toInt()
    println(
        when{
            a in (-14)..12 -> "True"
            a in 15..16 -> "True"
            a >= 19 -> "True"
            else -> "False"
        }
    )
}
