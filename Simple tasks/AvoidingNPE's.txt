Read a line (readln()).
If the line is not null, print: "Elvis says: <line>".
If the line is null, throw IllegalStateException.

Use the ?: throw construction.

Example:
Input: "hairstyle" → Output: "Elvis says: hairstyle"

fun main() {
    val line: String? = readlnOrNull()
    if (line != null) {
        println("Elvis says: $line")
    } else {
        throw (IllegalStateException())
    }
}


------------------------------------------------------------------

fun main() {
    val str: String? = readlnOrNull()
    println("Elvis says: ${str ?: throw IllegalStateException()}") 		// (The Elvis operator) ?:  return left value if it's not null, and right value if it's null 
}

Function check returns null if the string length > 5, otherwise returns the string itself.
In main, print 0 if check returns null, otherwise print the string's length.

Examples:
"danger" → 0
"Bob" → 3

fun main() {
    val argument = readln()
    println(check(argument)?.length ?: "0")
}


fun check(name: String): String? {
    return if (name.length > 5) null else name
}

Function round returns null if the number ≥ 1000, otherwise returns the number itself.
In main, print the number if it's not null, otherwise print 0.

Examples:
-5 → -5
5000 → 0

fun main() {
    val number = readln().toInt()
    println(round(number)?: 0)
}


fun round(number: Int): Int? {
    return if (number >= 1000) null else number
}
