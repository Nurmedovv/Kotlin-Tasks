В задаче требуется найти все полностью свободные строки и колонки на игровом поле размера 5 × 5.
Если разбить на шаги:
Нам дают координаты (строку и колонку) трех кораблей.
Каждый корабль «занимает» (блокирует) свою строку и свою колонку.
Программа должна проверить все числа от 1 до 5 и вывести:
На первой строке — номера свободных строк через пробел.
На второй строке — номера свободных колонок через пробел.

import java.util.Scanner

fun main() {
    val scanner = Scanner(System.`in`)
    val rows = mutableListOf(1, 2, 3, 4, 5) 		\\ создаем список от 1..5 (т.к сетка 5 * 5)
    val cols = mutableListOf(1, 2, 3, 4, 5)

    for (i in 1..3){					\\ зная, что корабля будет 3, запускаем цикл трижды (можно было использовать repeat(3))
        rows.remove(scanner.nextInt())			\\ отнимаем от карты первое число - координата строки
        cols.remove(scanner.nextInt())			\\ аналогично второе число - координата колонны
    }
    println(rows.joinToString(" "))			\\выводим оставшийся результат строк(цифры)
    println(cols.joinToString(" "))			\\то же самое, только для колонн 
}

Вывести все буквы английского алфавита, которые идут ДО введённой пользователем буквы.
Если разбить на шаги:
Программа считывает одну букву.Идёт по алфавиту от a до z.
Печатает каждую букву в одну строку.
Останавливается (break или return) прямо перед введённой буквой, не выводя её саму.


fun main() {
    val alphabet = "abcdefghijklmnopqrstuvwxy"
    val x = readln().first()
    for (i in alphabet) {		\\ можно заменить на for (i in 'a'..'z') и убрать alphabet
        if (i == x){
            break
        }
        print(i)
    }
}
