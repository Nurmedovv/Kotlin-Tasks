Sum of squares of even numbers up to a limit

Write a program in Kotlin that displays the sum of squares of even numbers from 1 up to a given limit. Take the limit as an integer input from the user. If the limit is less than 0, print 'Invalid Input'.

Sample Input 1:
10
Sample Output 1:
220

Sample Input 2:
5
Sample Output 2:
20

import java.util.Scanner                                   // Подключаем инструмент для чтения ввода пользователя

fun main(args: Array<String>) {                            // Главная точка входа, откуда начинается запуск программы
    val reader = Scanner(System.`in`)                      // Создаем объект reader для считывания данных из консоли

    val limit = reader.nextInt()                           // Читаем введенное пользователем целое число (предел)

    if (limit < 0) {                                       // Проверяем: если введенный предел отрицательный
        println("Invalid Input")                           // Выводим сообщение об ошибке, как требует условие
    } else {                                               // Иначе (если предел равен 0 или больше)
        var sum = 0                                        // Переменная для накопления суммы квадратов (изменяемая)
        var cur = 1                                        // Переменная-счетчик, начинаем проверку с единицы

        repeat (limit) {                                   // Запускаем цикл, который выполнится ровно limit раз
            if ( cur % 2 == 0 ) {                          // Проверяем текущее число: делится ли оно на 2 без остатка
                sum += cur * cur                           // Если четное, возводим в квадрат и прибавляем к сумме
            }                                              // Конец проверки четности числа
            cur++                                          // Переходим к следующему числу (увеличиваем на 1)
        }                                                  // Конец цикла repeat
        println(sum)                                       // Выводим итоговую сумму на экран
    }                                                      // Конец блока else
}                                                          // Конец главной функции программы

import java.util.Scanner

        val price = scanner.nextInt()			// Читаем стоимость следующей покупки

Программа рассчитывает время роста банковского вклада:
Ввод: Исходная сумма депозита (от 50 000 до 700 000).
Процесс: Каждый год сумма увеличивается на 7.1% (умножается на 1.071). (в условии давалась формула: deposit = deposit * 1.071)
Финал: Программа должна определить, через сколько лет сумма вклада превысит порог в 700 000, и вернуть это количество лет.

fun findYears(depo: Double): Int {
    var deposit = depo				// Текущая сумма вклада, полученная на вход
    val interestRate = 1.071			// Коэффициент ежегодного увеличения (7.1%)
    val max = 700000				// Лимит, который необходимо превысить
    var years = 0				// Счетчик прошедших лет

    while (deposit <= max) {			// Повторяем, пока вклад не перешагнул лимит
        deposit = deposit * interestRate	// Начисляем проценты за текущий год
        years++					// Увеличиваем счетчик времени на 1 год
    }

    return years				// Возвращаем итоговое количество лет
}

Программа генерирует и выводит последовательность Фибоначчи:
Ввод: Одно целое положительное число n — количество членов последовательности, которое нужно вывести.
Процесс: Каждый следующий элемент равен сумме двух предыдущих. Ряд всегда начинается с 0 и 1.
Финал: Нужно вывести первые n чисел строго в одну строку, разделяя их запятой и пробелом (например, 0, 1, 1, 2, 3). После последнего числа запятой быть не должно.

import java.util.*

fun main(args: Array<String>) {
    val scanner = Scanner(System.`in`)		// Создаем сканер для чтения ввода

    val n = scanner.nextInt()			// Считываем количество нужных нам чисел

    var t1 = 0					// Первое стартовое число Фибоначчи
    var t2 = 1					// Второе стартовое число Фибоначчи
    var i = 0 					// Счетчик выведенных элементов (начинаем с нуля)
    var nextTerm = 0				// Переменная для вычисления следующего числа

    while (i < n) {				// Цикл выполняется ровно n раз
        print(t1)				// Печатаем текущее число Фибоначчи в строчку

        if (i < n - 1) {			// Если это число НЕ последнее в списке...
            print(", ")				// ...то дописываем после него запятую и пробел
        }
        
        nextTerm = t1 + t2			// Считаем новое (следующее) число Фибоначчи
        t1 = t2					// Сдвигаем первое окошко на место второго
        t2 = nextTerm				// Сдвигаем второе окошко на место нового числа
        
        i++					// Шагаем по счетчику кругов вперед
    }
}

Задача «FizzBuzz с интервалом»:

Перебор: Нужно пройтись по всем числам от первого до второго (включительно).
Вывод (для каждого числа на новой строке):
Если делится и на 3, и на 5 — пишем "FizzBuzz"
Если делится только на 3 — пишем "Fizz"
Если делится только на 5 — пишем "Buzz"
Если не делится ни на что из этого — пишем само число.


fun main() {
    val n = readln().toInt()
    val m = readln().toInt()
    for (i in n..m) {
       when {
           i % 3 == 0 && i % 5 == 0 -> println("FizzBuzz")
           i % 3 == 0 -> println("Fizz")
           i % 5 == 0 -> println("Buzz")
           else -> println(i)
        }
    }
}
