Write a function that takes a List<Any> and returns a new List<Any> where:
Every Int element is multiplied by 2.
All other elements stay unchanged.
Use is / !is operators to check types.

Example:
[1, "hello", 3, true] → [2, "hello", 6, true]



fun multiplyInts(list: List<Any>): List<Any> {
    val result = mutableListOf<Any>()
    for (item in list) {
        when (item) {
            is Int -> result.add(item * 2)
            !is Int -> result.add(item)
        }
    }
    return result
}
