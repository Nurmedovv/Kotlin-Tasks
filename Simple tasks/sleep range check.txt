Требуется проверить, входит ли время сна H в здоровый диапазон от A до B включительно.
Что делать:

   1. Считать три числа: A (минимум), B (максимум), H (фактический сон).
   2. Вывести Normal, если H находится в пределах от A до B (включая границы).
   3. Вывести Deficiency, если H строго меньше A.
   4. Вывести Excess, если H строго больше B.



fun main() {    
    val (a, b, h) = List(3) {readln().toInt()}
    println( if (h in a..b) "Normal" else if (h > b) "Excess" else "Deficiency")
}

fun main() {    
    val a = readln().toInt()
    val b = readln().toInt()
    val h = readln().toInt()

    if (h in a..b){
        println("Normal")
    } else if (h < a){
        println("Deficiency")
    } else {
        println("Excess")
    }
}
