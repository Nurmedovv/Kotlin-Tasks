Вход: 4 аргумента с дефолтными значениями (возраст, пробег, макс. скорость, коробка автомат).
Логика:Вычесть по 2000$ за каждый год возраста.
Изменить цену на 100$ за каждый км/ч разницы со скоростью 120 км/ч.
Вычесть по 200$ за каждые полные 10 000 км пробега.
Прибавить 1500$, если коробка — автомат.
Вывод: напечатать (println) итоговую стоимость.


fun carPrice(old: Int = 5, kilometers: Int = 100_000, maximumSpeed: Int = 120, automatic: Boolean = false){
    var price: Int = 20_000
    price = price - (2000 * old)
    price += ((maximumSpeed -120) * 100)
    price -= (kilometers / 10_000) * 200 
    if (automatic) {
        price += 1500
    } 
    println(price)
}

Задача требует написать функцию для вычисления периметра многоугольника:
Суть: рассчитать сумму длин всех сторон фигуры по координатам вершин.
Вход: координаты для 3 или 4 точек.Особенность: если 4-я точка не передана, она по умолчанию должна принимать координаты 3-й точки (чтобы четырёхугольник превратился в треугольник).
Инструмент: для расчёта длины каждой стороны используется встроенная функция Math.hypot(Δx, Δy).
Вывод: функция возвращает общее число (Double) — периметр.

import kotlin.math.hypot

fun perimeter(x1: Double, y1: Double, x2: Double, y2: Double, x3: Double, y3: Double, x4: Double = x3, y4: Double = y3): Double {
    val a = hypot(x1 - x2, y1 - y2)
    val b = hypot(x2 - x3, y2 - y3)
    val c = hypot(x3 - x4, y3 - y4)
    val d = hypot(x4 - x1, y4 - y1)
    
    return a + b + c + d
}

Нам нужно написать банковскую программу, которая рассчитывает сложный процент по вкладу.
Параметры по умолчанию: Вклад открывается на 1000$ (amount), под 5% годовых (percent), на 10 лет (years).
Входные данные: 
Программа получает на вход две строки:Название параметра, который клиент хочет изменить ("amount", "percent" или "years").
Новое целое число для этого параметра.
Логика: Изменить нужно только один указанный параметр, а остальные два должны остаться дефолтными.
Формула: finalAmount = startingAmount * (1 + yearlyPercent / 100) в степени years.
Вывод: Программа должна вывести только целую часть от полученной итоговой суммы (дробную часть нужно отбросить).


import kotlin.math.pow

fun soft (stAm: Int = 1000, yrPrc: Int = 5, numOfYrs: Int = 10): Int =			\\ параметры с типом Int, и того же типа возвращаемый тип
   (stAm * (1.0 + (yrPrc.toDouble() / 100.0)).pow(numOfYrs)).toInt()		\\ формула по задаче. pow(возведение в(нужную нам) степень) требует Double. в конечном итоге конвертируем в Int

fun main() {
    println (when (readln()) {					\\ напечатать (когда(входная строка)) равна:
        "amount" -> soft(stAm = readln().toInt())		\\ "amount" -> переписываем начальное значение аргумента функции soft StAm на новое, прочитанное значение Int п  
        "percent" -> soft(yrPrc = readln().toInt())		аналогично для других значений
        "years" -> soft(numOfYrs = readln().toInt())
        else -> "Enter correct parameter"
    })
}
