Программа читает число с плавающей запятой (Double).
Нужно вывести его с разделителем тысяч (запятая) и ровно с 2 знаками после запятой.

Пример:
Вход: 1264.86453
Выход: 1,264.86


import java.util.Locale

fun main() {
    val value = readln().toDouble()
    println(String.format(Locale.US, "%,.2f", value))
}

Нужно вернуть отформатированную строку:
число с заданным количеством знаков после запятой,
дополненное пробелами слева до указанной ширины.

Дана строка.
Нужно определить, сколько букв нужно вставить, чтобы в строке не было трёх и более гласных или трёх и более согласных подряд.
Вывести минимальное количество вставок.

Гласные: a, e, i, o, u, y
Согласные: все остальные буквы.

fun main() {                                                                      // точка входа в программу
    val word = readln()                                                           // читаем строку с клавиатуры
    var count = 0                                                                 // счётчик вставленных букв
    var length = 0                                                                // длина текущей последовательности гласных/согласных
    var prevType = ""                                                             // тип предыдущей буквы ("vowel" или "consonant")

    for (ch in word) {                                                            // проходим по каждому символу в строке
        val isVowel = ch in "aeiouy"                                              // проверяем, является ли буква гласной (true/false)
        val currentType = if (isVowel) "vowel" else "consonant"                   // определяем тип текущей буквы

        if (currentType == prevType) {                                            // если тип не изменился
            length++                                                              // увеличиваем длину последовательности
        } else {                                                                  // если тип изменился
            length = 1                                                            // сбрасываем длину в 1 (текущая буква)
        }

        if (length == 3) {                                                        // если набралось 3 подряд одинаковых типа
            count++                                                               // нужна вставка → увеличиваем счётчик
            length = 1                                                            // после вставки длина последовательности становится 1
        }

        prevType = currentType                                                    // сохраняем тип текущей буквы для следующего шага
    }

    print(count)                                                                  // выводим количество вставок
}

Дана строка. Нужно посчитать процент символов G и C (гуанин и цитозин) от всей длины строки.
Регистр не важен. Результат — число типа Double.

Пример:
"acggtgttat" → G и C = 4, длина = 10 → 40.0

fun main() {
    val lower = readln().lowercase()
    val count = lower.count { it == 'g' || it == 'c'}
    val result = ((count.toDouble() / lower.length) * 100)
    println(result)
}

Дана строка URL с параметрами (после ?).
Нужно вывести все параметры в формате "ключ : значение".
Если значение отсутствует → "not found".
Если есть параметр pass (и он не пустой) → после всех параметров добавить строку "password : <значение>".
Порядок параметров сохраняется.

fun main() {
    val url = readln()
    val query = url.substringAfter("?")
    val params = query.split("&")

    var passValue = ""

    for (param in params) {
        val parts = param.split("=")
        val key = parts[0]
        val value = if (parts.size > 1) parts[1] else ""

        if (key == "pass") {
            passValue = value
        }

        val displayValue = if (value.isEmpty()) "not found" else value
        println("$key : $displayValue")
    }

    if (passValue.isNotEmpty()) {
        println("password : $passValue")
    }
}
